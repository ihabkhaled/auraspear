# AI Runtime Boot

Load this before planning, auditing, editing, testing, reviewing, delegation, or an expensive command.

1. State the exact objective, observable success, finite Definition of Done, scope, and exclusions.
2. Load `.ai/rules/00-master-rules.md` and route only relevant context through `.ai/context/context-index.json`.
3. Keep one active work item, nesting at most 3, same-strategy attempts at most 3, and critic rounds at most 2.
4. Use repository evidence. Classify discoveries as BLOCKER, REQUIRED, OPTIONAL, or UNRELATED; park the last two.
5. Count progress only when a requirement, blocker, deliverable, or verification state changes.
6. Verify with the smallest sufficient proof, run mandatory gates once after relevant changes, then stop when done.
7. Communicate in 1-5 direct, concrete lines unless correctness requires more.

Repository-specific engineering rules in `CLAUDE.md` remain authoritative.
