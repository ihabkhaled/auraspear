# Executive Function Cases

| Case                    | Signal                               | Expected control                 |
| ----------------------- | ------------------------------------ | -------------------------------- |
| Attention drift         | unrelated debt discovered            | classify and park                |
| Scope drift             | local feature grows into redesign    | scope guard returns to objective |
| Recursive decomposition | nesting exceeds 3                    | return to parent task            |
| Retry loop              | equivalent failure occurs 3 times    | strategy reset with novelty      |
| Verification loop       | proven check repeats unchanged       | accept sufficient evidence       |
| Critic loop             | optional refinements exceed 2 rounds | park and terminate               |
| Context loop            | same architecture reread             | use fresh cached context         |
| Livelock                | many actions, unchanged acceptance   | reduce scope and switch strategy |
| Deadlock                | no productive next action            | staged recovery or exact blocker |
| Hallucinated knowledge  | repository claim lacks source        | mark unknown and inspect source  |
| Premature completion    | DoD item lacks proof                 | remain in verification           |
| Completion avoidance    | DoD is proven, optional work appears | record follow-up and stop        |
