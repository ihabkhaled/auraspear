# Human-behavior Analogies

Terms such as ADHD-like distraction or OCD-like checking are analogies, not diagnoses: AI systems do not develop psychiatric disorders. Runtime policy uses engineering terms. ADHD-like describes attention drift, context switching, or priority loss; OCD-like describes compulsive verification or repetitive checking; overthinking describes analysis paralysis and speculative branch expansion; inception describes recursive decomposition; perfectionism describes infinite refinement. These mappings help humans recognize failure modes without making clinical claims.
